Quick reference

Revision guide

Short explanations and key facts to check before a quiz. These are summaries, not a replacement for your class notes.

Binary and denary

Binary is base 2 and uses only 0 and 1. Each position is worth twice the position to its right.

8-bit place values: 128, 64, 32, 16, 8, 4, 2, 1.

To convert binary to denary, add the place values where there is a 1. To convert denary to binary, find which place values add up to the number.

Hexadecimal

Hexadecimal is base 16. It uses 0–9 and A–F, where A=10, B=11, C=12, D=13, E=14 and F=15.

One hexadecimal digit represents exactly four binary bits. Split an 8-bit binary number into two groups of four to convert it.

Binary shifts

A logical left shift moves every bit left and adds zeroes on the right. For positive unsigned values, each left shift multiplies by 2.

A logical right shift moves bits right and adds zeroes on the left. Each right shift divides by 2, discarding any remainder. Bits shifted out are lost.

Data representation

A bit is one binary digit. 8 bits make 1 byte. Storage is commonly measured in KB, MB, GB and TB.

Images use pixels. More pixels and more bits per pixel usually mean a larger file. Sound is sampled: a higher sample rate or bit depth usually increases file size.

Text is represented using character sets such as ASCII and Unicode.

Logic gates

AND outputs 1 only when both inputs are 1. OR outputs 1 when at least one input is 1. NOT reverses the input.

XOR outputs 1 when the inputs are different. A truth table lists every possible input combination and its output.

Algorithms

An algorithm is a precise set of steps to solve a problem. Common tools include sequence, selection (if) and iteration (loops).

Linear search checks items one at a time. Binary search repeatedly halves a sorted list. Trace tables help track variable values as an algorithm runs.

Networks and security

A LAN covers a small area. A WAN covers a larger area. Routers connect networks and switches connect devices on a LAN.

Protocols are agreed rules. HTTP/HTTPS are used for web pages, DNS looks up domain names, and TCP helps deliver data reliably.

Phishing tries to trick people into revealing information. Use strong unique passwords, updates and multi-factor authentication.

Python essentials

= assigns a value; == compares values. Indentation defines code blocks. Lists start at index 0.

if makes a decision, for and while repeat code, and return sends a value back from a function.

How to revise effectively

Try a short quiz without notes, read the explanation for every mistake, then retry the topic later. Practise writing out working for number conversions instead of guessing.

Quick reference

Formula sheet

Useful rules and formulas for common Computer Science calculations.

Binary and hexadecimal

8-bit place values: 128, 64, 32, 16, 8, 4, 2, 1.

Binary to denary: add the place values where the bit is 1.

Hex to binary: each hexadecimal digit represents 4 bits.

Binary to hex: split the binary number into groups of 4 bits.

Storage units

1 byte = 8 bits.

1 KB = 1,000 bytes (or 1,024 bytes in some contexts). Check which convention a question uses.

File size in bits = number of items × bits per item.

Image size

Uncompressed image size (bits) = width × height × colour depth.

Divide by 8 to convert bits to bytes.

Sound size

Uncompressed sound size (bits) = sample rate × duration × bit depth × number of channels.

Divide by 8 to convert bits to bytes.

Binary shifts

Each logical left shift multiplies an unsigned value by 2, if no significant bits are lost.

Each logical right shift divides by 2 and discards remainders.

Networks

Download time = file size (bits) ÷ connection speed (bits per second).

Remember to convert bytes to bits before using a speed measured in bits per second.
